# Конфигуратор Zeekr 9X

Только конфигуратор: без шапки, логотипа, подвала и цен. Его собирают в сборку и встраивают в страницу модели на сайте.

Посмотреть: https://tema-mail.github.io/zeekr-9x-konfigurator/ (закрыт от индексации).
Локально: `python3 -m http.server 8932`, затем http://127.0.0.1:8932/

## Что выбирает человек
Места (6 или 5), версия (Max, Ultra, Hyper, «Яохэй»), батарея 55 или 70 кВт·ч, пакет помощи водителю H7 или H9,
цвет кузова (6), декор кузова (до 5), диски (актуальные 22″ кованые: «Синъяо» с 4- или 6-поршневыми суппортами,
зеркальные, чёрные «Яохэй»), цвет салона, один или два передних экрана, поворотные кресла второго ряда и фаркоп.
20″ и 21″ диски Zeekr сейчас не продаёт (в их конфигураторе «заменены на 22″»), поэтому их нет.

Правила совместимости взяты из официального конфигуратора: глянцевый хром – только с белым кузовом,
чёрный декор и пакет «Яохэй» – только с чёрным, чёрные диски – только в пакете «Яохэй». Выбор подстраивается сам.

## Картинки
Официальные рендеры Zeekr конкретной сборки (zeekrlife.com, раздел заказа): главный кадр без фона, три студийных ракурса
(спереди ¾, сбоку, сзади ¾) и салон. На картинке всегда тот цвет, декор, диски и лидары, которые выбраны.
86 сборок кузова × 4 кадра + 18 вариантов салона, всё в WebP: `img/zeekr-9x/ext/{H7|H9}_{цвет}_{декор}_{диски}--{вид}.webp`.

## Встраивание в сайт
Скопировать блок `<div class="z9" data-z9>…</div>` из `index.html`, подключить `css/konfigurator.css`,
`js/zeekr-9x-data.js`, `js/konfigurator.js`, положить рядом папку `img/`.
Цвета меняются токенами `--z9-*` в начале CSS (светлая и тёмная тема).

Сборка для формы заявки сайта:
```js
document.querySelector('[data-z9]').addEventListener('zeekr9x:change', e => {
  form.config.value = e.detail.text;   // «Zeekr 9X Ultra, 6 мест, 70 кВт·ч, H9: …»
  form.configUrl.value = e.detail.url; // ссылка, которая открывает эту же сборку
});
// или в любой момент: window.Zeekr9X.get()
```
Сборка хранится в адресе страницы (`#v=55&b=001&a=012&p=002&k=021&w=026&i=008&s=033&x=017`) – такой ссылкой можно поделиться.

## Как обновить данные
Инструменты в `tools/` (нужны Python 3, Playwright, Pillow; запросы идут с российского или китайского адреса –
zeekrlife.com не отвечает адресам из Европы):
1. `sniat-opcii.py` – открывает страницу заказа 9X и снимает версии и опции через их API → `z9x-raw.json`;
2. `svod.py` – правила совместимости и список нужных кадров → `model.json`;
3. `skachat.py` – скачивает кадры в `raw/` (6 потоков, повторы);
4. `kadry.py raw` – WebP в `img/zeekr-9x/`;
5. `dannye.py js/zeekr-9x-data.js` – данные для страницы (названия по-русски заданы в нём).

Данные сняты 11.11.2026, модель Zeekr 9X 2025–2026 модельного года (modelInfoId 10).
